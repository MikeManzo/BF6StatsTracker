## 🔧 Steps You Need to Complete

### Step 1: Add Sparkle Package via Xcode

1. Open `BF6StatsTracker.xcodeproj` in Xcode
2. Select the project in the navigator
3. Select the `BF6StatsTracker` target
4. Go to the "Package Dependencies" tab
5. Click the `+` button
6. Enter this URL: `https://github.com/sparkle-project/Sparkle`
7. Choose "Up to Next Major Version" with `2.0.0`
8. Click "Add Package"
9. Select "Sparkle" library and click "Add Package"

### Step 2: Generate EdDSA Keys

You need to generate cryptographic keys to sign your updates:

1. **Download Sparkle Tools:**
   ```bash
   cd ~/Downloads
   curl -L -o Sparkle-2.8.1.tar.xz https://github.com/sparkle-project/Sparkle/releases/download/2.8.1/Sparkle-2.8.1.tar.xz
   tar -xf Sparkle-2.8.1.tar.xz
   cd Sparkle-2.8.1
   ```

2. **Generate Keys:**
   ```bash
   ./bin/generate_keys
   ```

   This will:
   - Create a private key in your macOS Keychain (keep this safe!)
   - Output a public key to the terminal

3. **Copy the Public Key:**
   - You'll see output like: `SUPublicEDKey = "abcd1234..."`
   - Copy the key (the part inside the quotes)

### Step 3: Update Info.plist

1. Open `BF6StatsTracker/Info.plist`
2. Replace `YOUR_PUBLIC_KEY_WILL_GO_HERE` with your actual public key
3. Replace `YOURUSERNAME` with your GitHub username in the `SUFeedURL`

Example:
```xml
<key>SUFeedURL</key>
<string>https://raw.githubusercontent.com/yourname/BF6StatsTracker/main/appcast.xml</string>
<key>SUPublicEDKey</key>
<string>actual-key-from-generate_keys-command</string>
```

### Step 4: Test Build

1. Build the project in Xcode (Cmd+B)
2. If there are no errors, run the app
3. Go to Settings → Updates to verify the UI appears correctly
4. The "Check for Updates" menu item should be visible in the app menu

**Note:** The update check will fail until you create an appcast.xml file, which is expected.

## 📦 Creating Your First Release

### Option A: Manual with Sparkler (Recommended for First Release)

1. **Download Sparkler:**
   - Visit: https://www.sparkler.app
   - Download and install

2. **Archive Your App:**
   - In Xcode: Product → Archive
   - When done, click "Distribute App"
   - Choose "Copy App"
   - Save the .app somewhere

3. **Create Release with Sparkler:**
   - Open Sparkler
   - Drag your .app into Sparkler
   - Sparkler will:
     - Create a signed DMG
     - Generate/update `appcast.xml`
     - Sign everything with your EdDSA key

4. **Publish to GitHub:**
   - Go to your GitHub repo
   - Click "Releases" → "Create a new release"
   - Tag: `v1.0.0` (or whatever version)
   - Upload the DMG created by Sparkler
   - Publish release

5. **Commit appcast.xml:**
   ```bash
   git add appcast.xml
   git commit -m "Add appcast for v1.0.0"
   git push
   ```

### Option B: Automated with GitHub Actions (For Later)

Once you're comfortable with manual releases, you can set up GitHub Actions for automation. I can help you with that when you're ready.

## 🔒 Security Notes

1. **Private Key**: Your private EdDSA key is stored in macOS Keychain. Never commit it to git!
2. **Public Key**: Safe to commit in Info.plist
3. **GitHub Secrets**: If you use GitHub Actions, you'll need to add the private key as a secret

## ❓ Troubleshooting

### "Check for Updates" is disabled
- Make sure Sparkle package was added successfully
- Check that UpdaterService.swift is importing Sparkle correctly
- Build and clean the project

### Updates not detected
- Verify `SUFeedURL` in Info.plist points to correct appcast.xml URL
- Check that appcast.xml is accessible (visit the URL in a browser)
- Verify the version in appcast.xml is higher than current version

### Signature verification fails
- Ensure you're using the same private key that generated the public key
- Re-generate the appcast with `generate_appcast` tool if you changed keys
